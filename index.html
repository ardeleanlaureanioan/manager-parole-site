Manager Parole

Parolele și informațiile tale importante, într-un seif local criptat. Cu backupuri sub controlul tău și sincronizare opțională între calculator și telefon.

Seif criptatFără reclameGoogle Drive opțional

Seif local

Stochează parole, conturi, note și câmpuri personalizate pe dispozitiv. Datele seifului sunt criptate și se deschid după deblocare.

Windows și Android

Folosește seiful pe calculator și telefon. Pe Android, biometria poate debloca seiful dacă este disponibilă și configurată.

Sincronizare Google Drive

Conectarea este opțională. Prin permisiunea limitată drive.file, aplicația sincronizează propriul document criptat în contul tău Google.

Backup și restore

Exportă snapshoturi criptate în fișiere .pvbackup și restaurează copia aleasă. Backupul manual este separat de fișierul curent de sincronizare.

Securitate, cu limite explicite

Manager Parole folosește Argon2id și AES-256-GCM pentru protejarea datelor. Parola principală nu este trimisă la Google. Sincronizarea trimite conținutul seifului numai în formă criptată, fără un server propriu al dezvoltatorului.

Nu vindem datele utilizatorului, nu afișăm reclame și nu folosim datele Google pentru publicitate. Aplicația și acest site nu includ analytics sau tracking implementat de dezvoltator.

Păstrează parola principală și backupurile. Criptarea nu înlocuiește copiile de siguranță. Pierderea parolei poate face datele nerecuperabile.

English overview

Manager Parole is a local-first password manager for Windows and Android. Vault data is encrypted. Optional Google Drive synchronization uses the limited drive.file scope and stores encrypted vault content only. The master password is not sent to Google. The app has no developer-operated data server, ads or built-in analytics. Encrypted backups remain under the user's control.
